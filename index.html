Punto de partida

Una página para aprender haciendo

Construirás Tu dinero, con calma, una página educativa con consejos sobre presupuesto, ahorro y hábitos. Su propósito es informar de forma general; evita prometer ganancias o presentar recomendaciones como asesoría personalizada.

HTML describe la estructura y el significado; CSS define la apariencia. Bootstrap ofrece componentes y utilidades; Tailwind propone combinar utilidades pequeñas directamente en el HTML. Ambos siguen usando CSS: comprender el modelo de caja, Flexbox y Grid te permite elegir clases con criterio.

Cómo usar esta guía. Los objetivos siguen los 12 MiniRetos de Moodle, pero la temática, los nombres de carpeta y la integración se adaptan a este proyecto. Revisa las instrucciones originales si tu docente exige rutas o entregas literales de Rueda Libre.

Al finalizar tendrás un prototipo, un kit de componentes, una landing adaptable, una comparación argumentada, un repositorio publicado y una bitácora de aprendizaje y uso de IA.

Preparación

Antes de escribir clases

Necesitas Node.js y npm, un editor, navegador y Git. Comprueba node --version y npm --version. Abre una carpeta de trabajo nueva; los comandos siguientes se ejecutan en su terminal. Necesitas conexión para instalar paquetes y consultar fuentes.

Usaremos finanzas/ como carpeta del proyecto del estudiante. El prototipo usa Play CDN para experimentar; la versión entregable usa Tailwind CLI, que genera el CSS a partir de las clases encontradas en tus archivos.

Puente de conocimientos

Componentes, comportamiento e identidad

Antes de trabajar con Tailwind, observa cómo Bootstrap reúne estilos y comportamiento. Esta práctica independiente retoma los contenidos de componentes y personalización del material de Moodle, con el contexto de consejos financieros. No es necesario mezclar Bootstrap y Tailwind en la misma página.

Qué está pasando

  • Navegación y botones: navbar-expand-md cambia la presentación en pantallas medianas. El botón activa collapse; data-bs-target debe coincidir con el id del menú. Comprueba también aria-expanded y el foco con teclado.
  • Cards y carrusel: la grilla organiza las tarjetas y el carrusel usa controles anterior y siguiente. El bundle habilita sus interacciones; prueba que sean utilizables con teclado y evita movimiento automático innecesario.
  • Formulario, alerta y modal: required y type="email" permiten al navegador detectar datos inválidos. was-validated muestra los estilos de Bootstrap; el script de ejemplo impide cualquier envío. Cierra el aviso y prueba el modal con el botón y la tecla Escape.
  • Identidad: --bs-primary y --bs-primary-rgb son variables globales; el botón tiene variables propias --bs-btn-*. La clase marca complementa el framework. Un icono decorativo usa aria-hidden; un botón que solo tenga icono necesita nombre accesible.

Compara con Tailwind: Bootstrap proporciona componentes y comportamientos listos para configurar; en Tailwind construirás la apariencia combinando utilidades y necesitarás lógica adicional para interacciones equivalentes. Revisa que texto y fondo alcancen un contraste adecuado.

Comprueba y registra: prueba el menú en móvil, cambia de diapositiva, envía el campo vacío y con un correo válido, abre y cierra el modal, y personaliza el color. Anota en la bitácora qué hiciste, qué aprendiste y cómo verificaste cualquier ayuda de IA.

Consulta la documentación de navbar, cards, carrusel, validación, alertas, modal, variables CSS e iconos.

Reto 01

Tu primer prototipo

Crea finanzas/prototipo.html. Este archivo muestra una portada sin instalar dependencias. El CDN de juego es solo para desarrollo; no es el método de publicación final.

prototipo.html 
<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Tu dinero, con calma</title>
  <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
</head>
<body class="bg-stone-50 text-slate-800">
  <main class="mx-auto max-w-5xl px-6 py-16">
    <p class="font-bold text-emerald-700">Educación financiera</p>
    <h1 class="mt-4 text-4xl font-bold">Pequeños hábitos, grandes decisiones</h1>
    <p class="mt-4 max-w-xl">Aprende a organizar tus gastos y construir un ahorro a tu ritmo.</p>
    <a class="mt-6 inline-block rounded-lg bg-emerald-700 px-5 py-3 text-white" href="#consejos">Explorar consejos</a>
    <section id="consejos" class="mt-16"><h2 class="text-2xl font-bold">Empieza por aquí</h2></section>
  </main>
</body>
</html>

mx-auto centra el contenedor; px-6 da espacio horizontal y max-w-5xl limita el ancho. Inspecciona las reglas en DevTools y compáralas con CSS que escribirías tú.

Entrega: prototipo con portada y enlace funcional. Registra lo aprendido en tu bitácora.

Reto 02

Del prototipo al proyecto real

Desde la carpeta finanzas, instala Tailwind 4 y su CLI. El primer comando crea package.json; el último observa cambios y genera el CSS.

Terminal · dentro de finanzas 
npm init -y
npm install -D tailwindcss @tailwindcss/cli
mkdir -p src
printf '@import "tailwindcss";\n' > src/input.css
npx @tailwindcss/cli -i ./src/input.css -o ./output.css --watch

Copia el HTML del prototipo a index.html, elimina el script del CDN y enlaza <link rel="stylesheet" href="./output.css"> dentro de head. Mantén la terminal activa. Abre index.html con Live Server; al guardar una clase nueva comprueba que el CSS se regenera.

Crea tres variantes de botón: principal, secundario y deshabilitado. Usa button para acciones y a para navegación; agrega estados hover:, focus-visible: y disabled:. Detén el observador con Ctrl+C.

Entrega: proyecto CLI con portada y tres botones. Anota qué cambió entre CDN y CSS generado.

Reto 03

Tarjetas que enseñan

En index.html agrega tres tarjetas para presupuesto, ahorro y gastos. Repite una estructura semántica coherente y cambia título, explicación y categoría. Una tarjeta puede partir de este ejemplo:

HTML · dentro de la sección de consejos 
<article class="rounded-xl border border-stone-200 bg-white p-6 shadow-sm">
  <p class="text-sm font-bold text-emerald-700">Presupuesto</p>
  <h3 class="mt-2 text-xl font-bold">Observa tus gastos</h3>
  <p class="mt-3 text-slate-600">Registra durante una semana lo que gastas y clasifica cada compra.</p>
</article>

p-6 es espacio interior; border marca el borde y shadow-sm añade profundidad. Cambia una clase cada vez y observa el efecto.

Entrega: tres tarjetas claras, con categoría expresada en texto y no solo en color.

Reto 04

Tu kit de componentes

Crea componentes.html y enlaza output.css. Reúne allí los tres botones, una tarjeta, tres alertas (información, éxito y advertencia) y dos campos: correo y celular. Asocia cada label con su input mediante for e id; usa type="email" y type="tel". Una confirmación dinámica puede usar role="status".

Entrega: kit navegable con teclado, con foco visible y textos de alerta comprensibles sin depender del color.

Reto 05

Arma la página completa

En index.html organiza encabezado, navegación, portada, consejos, sección de beneficios y pie. Reutiliza las tarjetas y botones del kit. Usa un único h1, encabezados en orden y enlaces que apunten a identificadores existentes.

Entrega: página completa en escritorio; explica en la bitácora qué partes son HTML y cuáles son decisiones visuales.

Reto 06

Diseña desde el celular

Las clases sin prefijo se aplican desde el tamaño pequeño. md: y lg: añaden reglas a partir de sus puntos de quiebre. En Bootstrap ya conociste el enfoque móvil primero; aquí cambia la forma de expresar cada regla.

HTML · contenedor de tarjetas 
<div class="grid grid-cols-1 gap-6 md:grid-cols-2 lg:grid-cols-3">
  <!-- Coloca aquí tus tres artículos de consejos. -->
</div>

Comprueba una, dos y tres columnas en DevTools, y verifica que no haya desplazamiento horizontal ni texto recortado.

Entrega: landing adaptable a móvil, tablet y escritorio, con capturas de comprobación.

Reto 07

La identidad también se programa

Define un color de marca en src/input.css, después de la importación. Luego usa bg-marca o text-marca en tus componentes y comprueba el contraste.

src/input.css 
@import "tailwindcss";
@theme {
  --color-marca: #166534;
}

Añade variantes como dark:bg-slate-900 dark:text-white al cuerpo y a las tarjetas. Por defecto, dark: responde a la preferencia del sistema; prueba ambos modos desde DevTools o desde el sistema operativo.

Entrega: kit y landing con identidad coherente y modo oscuro legible.

Reto 08

Bootstrap y Tailwind: decide con evidencia

Revisa las clases repetidas y mejora la legibilidad de tu HTML sin romper el diseño. Compara una sección equivalente hecha con Bootstrap y otra con Tailwind. En tu bitácora escribe una tabla con curva de aprendizaje, personalización, tamaño de archivos y casos de uso; termina con una recomendación razonada.

Mide el tamaño real de output.css y de los archivos CSS y JavaScript de Bootstrap que utilices. Indica si mediste tamaño transferido o tamaño del archivo, la versión y las herramientas usadas. No presentes una medición local como una regla universal.

Entrega: código organizado, capturas, mediciones y comparación escrita.

Reto 09

Un formulario que se entiende

Agrega una sección de inscripción a novedades con nombre y correo, etiquetas visibles, tipos adecuados, required y un botón. Prueba la validación del navegador. Si no hay servidor conectado, aclara que el formulario es una demostración y no recopila ni envía datos reales. Registra tu tiempo de trabajo.

Entrega: formulario accesible y validación nativa comprobada con datos válidos e inválidos.

Reto 10

Conecta las piezas

Enlaza la portada, las secciones, el kit y el formulario mediante una navegación coherente. Comprueba enlaces de ida y vuelta, identidad visual y funcionamiento tanto local como publicado. En Moodle este reto integra dos productos de Rueda Libre; aquí se adapta a las páginas de consejos financieros.

Entrega: páginas enlazadas, con rutas relativas comprobadas.

Reto 11

Un requerimiento de última hora

Añade una sección de tres planes de aprendizaje gratuitos: inicio, organización y seguimiento. Cada tarjeta debe describir acciones educativas concretas, sin prometer resultados financieros. Aplica Grid para la distribución, Flexbox para ordenar contenido y utilidades de espaciado para el modelo de caja.

Entrega: sección adaptable y tiempo real registrado en la bitácora.

Reto 12

Revisa, publica y explica

Comprueba el HTML, enlaces, imágenes, contraste, foco, formulario y tamaños de pantalla. Genera el CSS final con el comando siguiente desde finanzas/:

Terminal · compilación final 
npx @tailwindcss/cli -i ./src/input.css -o ./output.css --minify

Incluye el CSS generado en la publicación estática y excluye node_modules/ con .gitignore. Haz commits descriptivos por reto y publica el repositorio con GitHub Pages. Abre las URLs publicadas y comprueba que el CSS y las rutas funcionen.

Crea un README con descripción, tecnologías, enlaces publicados, capturas de escritorio, móvil y modo oscuro, comparación, aprendizajes y autor. Ensaya una demostración y registra la retroalimentación.

Entrega: repositorio, README, URLs, bitácora completa y demo. Verifica el contenido con el validador HTML del W3C.
