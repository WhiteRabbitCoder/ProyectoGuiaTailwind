Así trabajaremos

Elijan una misión, editen el HTML y pulsen Actualizar vista. Cuando esté lista, copien la sección y compártanla con quien integre la página del clan. Las cuatro misiones usan el mismo documento base para que sea fácil unirlas.

Antes de empezar
La vista previa necesita internet para cargar Tailwind Play CDN. El editor guarda borradores en este navegador; no se comparte en tiempo real. Descarga tu trabajo para conservarlo y compartirlo.

Vista previaLa vista previa está aislada y no envía formularios.

Ahora, junten las piezas

  1. Un integrante crea index.html con la base descargable. Cada equipo copia su sección terminada y se la entrega.
  2. El integrador reemplaza las marcas del documento con los aportes, en este orden: navegación, portada, consejos y formulario. Conserven un solo main y un solo h1.
  3. Prueben los enlaces, la visualización en celular, el foco del teclado y el formulario. Expliquen qué clases usaron y qué CSS producen.
  4. En la bitácora cada integrante registra su aporte, aprendizaje, uso de IA y cómo verificó lo que hizo. El clan documenta quién integró y cómo probó la página.
  5. Para el proyecto final, pasen de Play CDN a Tailwind CLI siguiendo la guía de instalación. El CDN es para practicar y no para producción.

La base usa Play CDN para facilitar esta práctica; no crea colaboración en tiempo real ni publica el sitio.
