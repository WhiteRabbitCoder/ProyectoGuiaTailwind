# Tu dinero, con calma · Guía de Tailwind

Guía práctica en español para aprender HTML, CSS y Tailwind CSS 4 mediante una página de consejos financieros. Contiene 12 retos, referencias y una bitácora para registrar aprendizaje y uso de IA.

Abre `index.html` en el navegador o visita GitHub Pages cuando esté habilitado. Para la práctica de Tailwind CLI se necesitan Node.js y npm.

## Skill de apoyo

La skill está en `.agents/skills/aprender-tailwind/SKILL.md`. En un entorno compatible que descubra skills en `.agents/skills`, abre este repositorio y solicita apoyo con la guía; también puedes invocarla como `$aprender-tailwind` si tu herramienta admite esa sintaxis. Sigue las instrucciones de tu herramienta si utiliza otra ubicación para instalar skills.

Los retos adaptan el material de Moodle de Riwi a un nuevo proyecto; consulta el material original para los requisitos literales de tu curso.

## Laboratorio del clan

Abre `laboratorio.html` para practicar cuatro secciones con vista previa y reunirlas manualmente en una página compartida. Los borradores son locales al navegador; no hay edición colaborativa en tiempo real.
